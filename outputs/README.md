# Output Artifacts

This directory contains saved outputs used to verify the manuscript tables and
figures without rerunning every model.

## `outputs/metrics/`

CSV metric files used for the main benchmark, multi-horizon forecast, anomaly
screening, computational profile, and strict few-shot transfer analysis.

Important files include:

- `probabilistic_one_step_five_seed_summary.csv`
- `probabilistic_one_step_five_seed_per_seed.csv`
- `probabilistic_multi_horizon_metrics.csv`
- `probabilistic_anomalies_summary.csv`
- `strict_best_recipe_test_summary.csv`
- `strict_best_recipe_per_window_test.csv`
- `compute_profiling.csv`
- `zero_training_baselines.csv`

## `outputs/figures/`

Saved figures generated by the notebook and scripts. Both PNG and selected PDF
versions are retained when available.
